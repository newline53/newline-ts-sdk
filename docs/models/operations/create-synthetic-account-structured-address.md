# CreateSyntheticAccountStructuredAddress

Structured wire address using ISO-style parsed fields. Accepted when your program's wire address configuration is set to `structured` or `both`. Required fields: `city` and `country`.


## Example Usage

```typescript
import { CreateSyntheticAccountStructuredAddress } from "newline-ts-sdk/models/operations";

let value: CreateSyntheticAccountStructuredAddress = {
  line1: "123 Main St",
  line2: "Suite 400",
  buildingNumber: "123",
  streetName: "Main St",
  city: "Cincinnati",
  state: "OH",
  postalCode: "45202",
  country: "US",
};
```
