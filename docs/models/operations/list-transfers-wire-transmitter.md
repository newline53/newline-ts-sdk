# ListTransfersWireTransmitter

Information about the Transmitter. Must be provided if the `initiator_type` is `transmitter`. Includes the transmitter's name, identifier, and address. The address format on requests depends on your program's wire address configuration. Responses always return all address fields; fields not applicable to the stored format are `null`.


## Example Usage

```typescript
import { ListTransfersWireTransmitter } from "newline-ts-sdk/models/operations";

let value: ListTransfersWireTransmitter = {
  name: "Marge's Roofing Inc",
  transmitterIdentifier: "123456789012345",
  line1: "123 Abc St.",
  line2: "Boring, Oregon 97009",
  line3: null,
  buildingNumber: "123",
  streetName: "Main St",
  city: "Cincinnati",
  state: "OH",
  postalCode: "45202",
  country: null,
};
```
