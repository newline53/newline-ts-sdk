# SyntheticAccountAch

Contains ACH-specific information. Only populated if the Synthetic Account is in the `ach_external` category.


## Example Usage

```typescript
import { SyntheticAccountAch } from "newline-ts-sdk/models/operations";

let value: SyntheticAccountAch = {
  accountType: "checking",
  counterpartyName: "Thelma's Flooring LLC",
};
```
