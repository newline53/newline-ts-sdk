# GetTransactionsAuthorization

Transaction Authorization information. Only present if authorization was required for a given transaction.


## Example Usage

```typescript
import { GetTransactionsAuthorization } from "newline-ts-sdk/models/operations";

let value: GetTransactionsAuthorization = {
  authorizationFinalizedAt: new Date("2024-10-09T00:12:53.729Z"),
  authorizationRequiredBy: new Date("2024-10-10T00:18:53.729Z"),
  authorizationStatus: "client_denied",
  deniedMemo: "denied memo",
  deniedReason: "debit_limit_exceeded",
};
```
